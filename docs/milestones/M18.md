## Findings and changes

- At 1101 CSS px, “Explore the set” and “Learn to play” wrapped after the smaller desktop padding stopped applying. Shop now uses compact link padding from 981 through 1200 px. The links stay in one row alongside the gallery thumbnails and retain a minimum 44 CSS px target height.
- The overview and piece lineup shared two adjacent 1 px borders, as did the detail cards and learning banner. Each transition now has a single brass rule. The parchment, charcoal, and burgundy backgrounds retain their approved treatments.
- “Go beyond chess.” is the Shop tagline. It now uses paragraph semantics and keeps its existing typography. The heading outline starts at “Dhess,” with level-two section headings and level-three feature and card titles.
- Below 761 CSS px, the overview showed only a narrow strip of a 151,310 B desktop scenery image. The 384 × 480 mobile WebP crop keeps the same positioning, scale and CSS fade. It saves 119,686 B on that request, a 79% reduction. The export crops the upper-left 384 × 480 pixels of the existing plate and uses WebP quality 95. In the 390 px lossless comparison, the first 70 × 100 rendered pixels below the rule differed by at most two values in any 8-bit channel. The full plate still loads at desktop widths.
- The inactive gallery board now uses native lazy loading and asynchronous decoding. The product layers remain eager and element dimensions are reserved. The thumbnails and board started at Low priority in Chrome. Chrome still fetched the 537,628 B shared board near startup because the lazy overview was within its load range. The savings measured on narrow pages come from the scenery crop.

Inspected Home, Learn, and Shop at the five table widths, 844 × 390 and 667 × 375 landscape, and breakpoint widths around the two-column showcase, lineup and section stacks. The viewport and text-geometry checks found no horizontal overflow or offscreen text. Reviewed the gallery, wrapped lineup, detail cards, banners and footer in the captures.

Cold requests selected the correct responsive scenery on Home and Learn and switched Shop’s overview plate at its mobile breakpoint. Cormorant Garamond 600 loaded locally and its OFL notice remains in `public/fonts/`. Checks found zero unexpected layout-shift entries, failed site requests or page JavaScript errors. Shop retains its English language declaration, title, description, viewport metadata and theme color.

All thumbnail targets exceeded 44 × 44 CSS px in the measured matrix. Overview and Explore the set accepted keyboard and pointer activation, exposed their headings and focus indicators, and opened as direct URLs. Checked the next Tab destinations and tested the fragment jumps with both the existing smooth scrolling and reduced motion.
- Activated shared primary and footer links and incoming Shop actions across Home, Learn, and Shop at six widths. Exercised both Shop Learn links by pointer and keyboard. Checked skip links, visible focus, mobile menu state, Escape focus return, and outside-click dismissal on Shop. Both purchase placements remain visible as “Unavailable” text outside the tab order.
- Reviewed Shop’s landmarks, heading hierarchy, image alternatives and visual reading order. The lineup exposes the names of all seven pieces in order. The gallery and learning scene each expose one description. The decorative icons, cloth, scenery and thumbnail images are omitted from the accessibility tree.

The sampled thumbnail, menu and Learn action borders reached at least 4.41:1 against adjacent pixels. The sampled gold focus outlines reached at least 5.66:1 against the underlying pixels. Verified that the two parchment fragments display their inset oxblood outlines on keyboard focus.
