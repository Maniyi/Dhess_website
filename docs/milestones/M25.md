# Milestone 25 — The Imperion learning popup

The King in Learn’s “Meet the pieces” gallery opens **Palace Movement** and **GBESELE Capture**. The lesson uses the approved rule text and the existing piece artwork. The movement example shows two jumps within a full 100-cell board. The capture example shows three assumed-undefended targets before one GBESELE and the Imperion remaining on E1 afterward, on two 50-cell half-boards. All coordinates are illustrative. [Design, interaction, and diagram guide](../design/learn-piece-popups.md)

## Verification

- Checked both lesson pages at 1440 × 1000, 1024 × 768, 768 × 1024, 390 × 844, 320 × 640, and mobile landscape 667 × 375. Checked 100/50/50 board cells, square geometry, control sizes and bounds, document and panel overflow, lesson visibility, text captions, font and image loading, and closed/open gallery dimensions. The narrow and landscape views use internal scrolling.
- Delayed mouse hover preserved focus and stayed open when the pointer entered the panel. Pointer departure closed an unengaged hover popup and left it open with focus inside. Checked mouse click, emulated tap, Enter, Space, both page selectors, Previous and Next, outside tap, Escape, the close button, focus return, forward and backward Tab, and keyboard scrolling.
- Inspected Chrome’s accessibility tree on desktop and emulated mobile for the named nonmodal dialog, trigger, active lesson heading, and hidden inactive lesson. Checked reduced-motion emulation and verified the popup had no animations and used immediate scrolling.
- Set Chrome’s actual **Page zoom** to **200%**. The CSS viewport changed from 1440 × 913 to 720 × 456 while visual viewport scale stayed at 1. Checked both lesson pages, fit, page navigation, and Escape focus return.
- Checked the active shared navigation item and followed a header link from each page at 1440 and 390 px. On each page at 390 px, checked mobile-menu Escape and focus return. At both widths, checked the four Learn chapter links and the three Shop gallery selections.
- Compared all four pages with their pre-edit baselines at the six viewport sizes. The final comparison preloaded images and used Chrome software rendering to resolve paint differences seen during early captures. All 24 full-page pairs and both dedicated gallery crops matched pixel for pixel. Document and section geometry also matched in all 24 page pairs. After the visual revision, the eight desktop and mobile page pairs at 1440 and 390 px and both closed-gallery pairs matched again.
- Chrome reported no site-authored console errors or HTTP failures in the interaction runs. `node --check script.js` and `git diff --check` passed.

Browser testing used headless Chrome 158.0.8127.37 on macOS. Touch and mobile landscape were emulated. Other browser engines, physical mobile devices, manual screen-reader use, and standalone accessibility scanners were outside this review.
