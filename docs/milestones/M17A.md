## Verification

- Reviewed both complete banners in Chrome 157 at the four viewport sizes above. Checked the knight silhouette, board details, warmth of the room, scenery transitions, and separate velvet edge. At 320 px the full capture extends below the viewport as it would on a scrollable page.
- Checked image dimensions and decoding, the font load, text bounds, the absence of horizontal overflow and cloth interference, and that browser requests and logs showed no failures or site-authored errors in the preview. Calculated a minimum sampled normal-state text contrast of 5.82:1 using the declared text colour and the rendered background with text hidden.
- Verified that Tab focuses “Learn to play,” the focus outline is visible, and Enter opens `learn.html` at all four widths. Checked the Chrome accessibility tree for the described knight and board scene and the Learn link. “Buy the game” carries a visible “Unavailable” status and stays outside the tab order.
- Ran `node --check script.js` and `git diff --check`. Verified 373 starting SHA-256 hashes covering the production HTML, CSS and JavaScript, approved artwork, public exports, fonts, and earlier previews. The artwork transparency checks verified clear top corners and the alpha ranges recorded in the asset guide.
- Physical devices, other browser engines, and manual screen-reader testing were outside this pass. Production-page insertion, full-page captures, and Home, Learn, and Shop interaction regression checks belong to Phase B.
