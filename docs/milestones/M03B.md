# Milestone 3B — European Edition introduction

Completed 19 November 2026. The approved introduction now follows the game facts strip on the homepage. All heading and feature copy is editable HTML, with an `h2` for the section and `h3` headings for its three features. The approved desktop and mobile parchment plates remain separate from the content; the mobile plate fades into the approved paper tile. The three approved transparent illustrations are lazy-loaded with intrinsic dimensions and descriptive alternatives. This milestone added no script or dependency and did not change the header, hero, facts, or menu code.

## Preview

From the project root:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open <http://127.0.0.1:8000/>.

## Validation

- Checked the live page in a browser at 1440, 1024, 390, and 320 px widths, after `document.fonts.ready`. The local Cormorant Garamond 600 face reported loaded at every width.
- The introduction plate and all three feature images loaded at each width. The mobile widths selected the mobile plate; desktop and tablet selected the desktop plate. The paper tile is visible in the mobile capture.
- No horizontal document overflow, clipped feature illustration, or missing text was observed at those widths. The 1024 px layout retained aligned three-column features; the mobile layouts stacked them in order.
- The 320 px full-page capture showed the header, hero, facts strip, and introduction in sequence. The mobile menu opened and closed with Escape, and no browser console errors were recorded.
- `git diff --check` passed. No project test or build script exists for this static HTML/CSS page.
