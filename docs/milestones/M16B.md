# Milestone 16B — Shop detail-card integration

“Explore the European Edition.” appears immediately below the seven-piece lineup. It uses the three approved card WebPs and warm parchment from [Milestone 16A](M16A.md), including the angled package with its decorated left spine. The eyebrow, section title, card headings, and descriptions are editable HTML. The three equal desktop columns stack at 760 CSS px and below. [Artwork sources, crop coordinates, and limitations](../design/shop-detail-assets.md)

The showcase’s “Explore the set” link reaches `#explore-the-set`. The destination follows Overview’s native fragment and focus pattern. Cards use a semantic list with descriptive image alternatives, intrinsic image dimensions, and lazy loading. The parchment and rules are decorative CSS. The cards have no controls.

## Local preview

From the repository root, run

```sh
python3 -m http.server 8139 --bind 127.0.0.1
```
