# Milestone 20A — “The idea” artwork review

Prepared 20 November 2026 for approval before About integration. The isolated composition puts the supplied copy on warm parchment and places the angled board to the right on desktop and beneath the copy on mobile. It uses the approved ivory Knight and Rook and an angle derived from the approved Learn board. The [artwork guide](../design/about-idea-assets.md) records provenance, file dimensions and sizes, layer placement, responsive crops, and departures from the mockup.

## Checks performed

- Rendered over local HTTP in Chrome 157.0.8103.80 at all six widths, using mobile emulation for the stacked layout. Visually inspected text legibility, the board angle, frame detail, resource colours, both silhouettes, contact shadows, and background transitions.
- Confirmed no horizontal overflow or offscreen text. Both piece image bounds fit within the scene and clear the copy at all six widths. All scene images decoded. The local Cormorant Garamond font loaded, and there were zero failed requests or site-authored browser errors. At 390 and 320 px with device scale factor 1 the browser selected the 780 px board.
- Chrome’s accessibility tree exposed a level-two heading and a single described artwork group. The board and figure layers have empty alternatives within that group. The parchment, sketches, and rule come from CSS.
- Verified alpha bounds for the board master, both derivatives, and the reused figure cutouts. `node --check script.js` and `git diff --check` passed. The working tree contains only new Phase A files. The production pages, styles, script, and approved art match HEAD.
