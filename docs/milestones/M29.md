# Milestone 29 — The Rook learning popup

Select **Rook** in Learn’s “Meet the pieces” gallery to open **The Rook**, subtitled **The Southern Africa Advisor**. Its single **Move & Capture** lesson pairs the approved ivory portrait with a parchment panel, gold frame, burgundy heading, and a fixed 10 × 10 diagram. The full piece guide remains pending. [Popup design and rules](../design/learn-piece-popups.md)

## Rules and diagram

The Rook moves any distance along a clear vertical or horizontal line. It cannot move diagonally or jump over pieces. A friendly-occupied square blocks travel and cannot be a landing square. A capture ends on the opponent’s square. The diagram shows four alternative actions, and its HTML caption provides the same example in text.

The SVG uses 100 explicit 40 × 40 cells with files A–J and ranks 1–10. The Rook starts on E5 at (180, 220). Every arrow starts there and ends at a square center.

| Action | Destination | Marker |
| --- | --- | --- |
| Move up | E10 (180, 20) | Solid gold arrow |
| Move left | A5 (20, 220) | Solid gold arrow |
| Move down | E4 (180, 260) | Solid gold arrow stops before the friendly Pawn on E3, outlined and labeled Blocked |
| Capture right | I5 (340, 220) | Dashed burgundy arrow ends on the opposing Knight |

## Validation

- Checked 100 board cells, alternating colors, rank and file labels, all piece locations, square-centered arrow endpoints, horizontal and vertical paths, and clear intermediate squares. The E4 arrow stops before the friendly Pawn, and the I5 arrow stops on the opposing Knight.
- Checked layout at all six listed viewport sizes. The panel and its close control fit, scrolled captions were reachable by keyboard, and opening kept the gallery and document geometry stable.
- Checked delayed mouse hover, no hover focus shift, pointer travel into the panel, departure with and without focus inside, mouse click, emulated tap and outside tap, Enter, Space, Escape, and the close button. Checked forward and reverse Tab exit, expanded states, cancellation of pending hover, and focus placement and return when switching among all five implemented pieces. Mystic and Pawn retain their static gallery entries.
- Inspected Chrome’s accessibility trees at desktop and mobile widths for the named nonmodal dialog and subtitle, close button, lesson heading, scroll region, and text equivalent. Under reduced-motion emulation the popup had no animations and used immediate scrolling.
- Set Chrome’s actual **Page zoom** to **200%**. The CSS viewport changed from 1440 × 913 to 720 × 456, device pixel ratio doubled, and visual viewport scale stayed at 1. Verified fit, keyboard scrolling to the caption, and Escape focus return.
- Rechecked all seven Imperion, Queen, Knight, and Bishop lesson views at all six viewport sizes for fit, lesson navigation where available, and Escape focus return.
- All 16 closed-page comparisons matched pre-change geometry and pixels at 1440, 1024, 390, and 320 px. The 1440 px About capture differed during the first batch and matched exactly in an isolated recapture. All 42 existing-lesson captures matched their pre-change pixels.
- Followed shared navigation links at 1440 and 390 px and checked mobile-menu Escape and focus return on all four pages. Tested all four Learn chapter links, all three Shop gallery views, and both Shop section links at those widths. The browser interaction run reported no site-authored console errors or failed assets. `node --check script.js` and `git diff --check` passed.

Testing used headless Chrome 158.0.8127.37 on macOS. Mobile touch and landscape were emulated. Physical mobile devices, other browser engines, manual screen-reader use, and a standalone accessibility audit remain untested.

## Changed files

- `learn.html` adds the Rook trigger, named dialog, editable lesson text and caption, and inline SVG diagram. It updates the Learn stylesheet and script cache keys.
- `styles.css` reuses the existing board colors, arrow and legend styling, and single-lesson layout. It adds the positioned blocker label.
- `script.js` lets the shared controller place the Rook panel to the left of its trigger when there is room. It uses the shared centered layout on touch and at narrow widths.
- `docs/design/learn-piece-popups.md` and `docs/homepage-pending-items.md` record the lesson and pending guide work. This report and `assets/previews/M29/` contain the review evidence.
