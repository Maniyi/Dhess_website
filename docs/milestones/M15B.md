# Milestone 15B — Shop piece lineup integration

The approved [Phase A composition](M15A.md) now appears directly below the Shop overview. “Every piece has a presence.” is an HTML heading above a single list in reading order. The King, Queen, Bishop, Rook, Mystic, Knight, and Pawn each use an independent approved image with a name, intrinsic dimensions, and native lazy loading. The charcoal and tabletop are CSS layers. The velvet and gold ornaments are decorative. [Artwork and placement](../design/shop-lineup-assets.md)

Desktop keeps all seven pieces on one baseline. Tablet uses a centered four-over-three arrangement. Mobile uses two columns with Pawn centered on the final row. The Shop lineup styles use dedicated selectors.

“Overview” reaches the existing section and “Learn to play” opens Learn. “Explore the set” remains unavailable pending its detail-card section, and “Buy the game” awaits an approved purchase destination. The lineup uses concept artwork. The figures and their arrangement leave final sculpt details, set contents, and gameplay rules to the approved product and rules references.
