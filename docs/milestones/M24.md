### Asset loading

The [782 px derivative](../../public/images/about/closing-box-782.webp) is **110,832 B**. It was proportionally downsampled with Lanczos from the approved [1563 px concept box](../../public/images/home/product-box-concept.webp), then encoded as WebP at quality 89, method 6. It saves **207,954 B (65.2%)** where selected. The original candidate is 318,786 B. Side-by-side Chrome renders at 1024 and 390 CSS px retained the silhouette, lettering, and visible detail at the displayed sizes. Fine packaging claims remain provisional.

At device scale factor 1, Chrome selected the smaller box at 1024, 768, 667 × 375, 390, and 320 px. It chose the original at 1440 px and at 390 px with device scale factor 2. The network log showed one candidate per image on cold load for the hero scenery, idea board, game-night picture, and box in all 21 About viewport runs.

## Checks run

**Automated browser checks.** Chrome 157.0.8103.80 served the local files via loopback HTTP. About passed document overflow, text clipping, image decode and dimension, local font, and request and console error checks at the five main sizes and at 599/600 × 375, 667 × 375, 667 × 500, 668 × 501, and 760/761 × 375. The run also covered 365/366, 700/701, 730, 760/761, and 900/901 px in taller viewports. The responsive rules selected both sides of their intended breakpoints. Close-up checks confirmed the three hero figures and both “The idea” figures fit their scenes at the five main widths and 667 × 375.

**Keyboard and pointer.** At 1440, 1024, 390, and 320 px, Chrome received native Tab, Enter, Space, Escape, and mouse events. All four pages exposed visible skip-link focus, moved focus to the main landmark when activated, and preserved link order and the current-page state in both navigation landmarks. The mobile menu closed on Escape with focus returned to its toggle. Clicking or focusing outside closed it. About also passed the landscape Escape check. All 96 distinct page-to-page navigation checks passed through the shared header by pointer and footer by keyboard. About’s brand links, header Shop action, and three closing links passed keyboard and pointer activation. “Learn to play” opened Learn, and “Explore the game” and “Shop the game” opened Shop. All three Shop gallery views passed keyboard and pointer selection with focus retention and stable stage dimensions. The overview, detail-card and Learn shortcuts activated. Both purchase placements and all five Learn guide or rulebook placements stayed unavailable and outside the tab order.

**Accessibility and zoom.** Chrome’s accessibility tree exposed one page heading, the expected section and card heading levels, nine named artwork groups or images, and appropriately named closing links. The artwork layers inside named scenes and the ornaments did not produce extra image or text stops. Checked the English language declaration, page title, and description against the hero copy. The lowest sampled foreground-to-rendered-background text contrast was **6.65:1** at 390 px across captures of the five main sizes and landscape. Chrome’s Page zoom setting was changed from 100% to **200%**. The resulting 640 × 436 CSS px layout showed no horizontal overflow, and the closing link retained a visible focus outline.

**Manual visual review.** Inspected the rendered captures for heading wrapping, readable paragraphs, section spacing and gold rules, face and crown crops, board silhouettes, cloth clearance, copy-first closing sections, visible focus and footer spacing. Compared the optimized box against the original at the same display sizes. The shared footer required no local styling changes.

`node --check script.js` and `git diff --check` passed. Browser automation used reduced-motion emulation for stable captures. No standalone accessibility scanner was used. Physical-device testing, other browser engines, manual screen-reader testing, and production performance were outside this local review.
